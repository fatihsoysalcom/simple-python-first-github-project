# Simple Python First GitHub Project

This example provides a minimal Python script intended as a "first project" for users learning Git and GitHub. It serves as the content that one would initialize a Git repository with, commit, and then push to GitHub using SSH, following the steps outlined in the accompanying technical article.

## Language

`python`

## How to Run

Save the code as `main.py`.
Open a terminal in the same directory and run:
`python main.py`
